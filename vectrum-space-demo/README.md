# Vectrum Space demo

Копия боевого сайта www.vectrumspace.eu. На ней пробуем новый фон для hero, не трогая настоящий сайт.

- `site/` — скачанная копия: страницы, RSC, скрипты, стили, картинки, тексты на 5 языках. Обновить: `npm run mirror`.
- `server.js` — отдаёт копию без зависимостей. Картинки `/_next/image` идут оригиналами, тексты подставляются по языку. Формы и прочие API отвечают 503. Копия закрыта от поисковиков.
- `demo/inject.html` — то, что добавляется на каждую страницу поверх копии (новый фон hero).

Запуск: `npm start` (порт из `PORT`, по умолчанию 10000).
Хостинг: Render web service из этой папки репозитория vectrum-posts (Root Directory `vectrum-space-demo`).
