# Vectrum Posts

Редактор постов для Instagram: выбираешь шаблон, вводишь и форматируешь текст, при желании подкладываешь картинку или видео и мелодию, скачиваешь MP4 или PNG.
Статический сайт без сервера и сборки: всё считается в браузере, файлы никуда не загружаются.

```
index.html        разметка страницы
css/app.css       стили
js/tokens.js      фирменные цвета
js/variants.js    шаблоны (вкладки) и форматы
js/engine.js      рисование анимаций на Canvas, портировано из vectrum-bg
js/text.js        заголовки: перенос строк и автоподбор размера
js/editor.js      интерфейс и скачивание
js/vendor/        Mediabunny 1.65.2: сборка MP4 в браузере (MPL-2.0)
fonts/            Raleway и Raleway Italic: латиница и кириллица
```

## Запуск локально

Нужен любой статический сервер, например:

```bash
npx http-server . -p 8000 -c-1
```

## Публикация

Сайт живёт на Render: https://vectrum-posts.onrender.com, статический сервис `vectrum-posts`, ветка `main`, без сборки.

## Новый шаблон

1. Добавь конфиг в `window.VARIANTS` в `js/variants.js`: он сам станет вкладкой.
2. Если движению нужен новый тип рисования, добавь его в `draw()` в `js/engine.js`.
   Всё движение считается от фазы цикла `p = frame / 300`, иначе цикл перестанет быть бесшовным.

## Ограничения

- MP4 собирается через WebCodecs: Chrome и Edge на компьютере. PNG работает везде, где работает Canvas.
- Звук в MP4 кодируется в AAC. Если браузер этого не умеет, редактор предлагает Chrome, Edge или видео без звука.
- Если загружена мелодия, она заменяет звук из видеофона. Без кнопки звука в файл попадает только видео.
- Видео в кодеке HEVC открывается не на всех компьютерах. Если браузер не может его прочитать, редактор показывает сообщение.
